# TSE Submission Package Readme

This package is built around the current canonical TSE manuscript files:

- main manuscript:
  `manuscript/tse_flagship/tse_flagship_main.md`
- appendix:
  `manuscript/tse_flagship/tse_flagship_appendix.md`

The editor-facing package files in `submission/` are the current ones to use:

- `submission/tse_cover_letter_current.md`
- `submission/tse_difference_note_current.md`
- `submission/tse_submission_metadata_current.txt`
- `submission/tse_comments_to_editor_current.txt`
- `submission/tse_upload_manifest_current.md`

Do not rebuild the package around archived or non-canonical files such as
`archive/legacy_drafts/manuscript/full-draft.md`, and do not use missing
legacy path assumptions from the older `41/42/43/44` naming pattern. The
frozen JSS witness archive at `manuscript/jss_witness_archive/` is not an
active submission source.
